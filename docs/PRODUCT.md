# NoGameNoLife 产品方案 v1

> 一句话：**把自己的人生做成一张 RPG 角色面板**。你做的每件真实的事，都会变成角色的经验和属性；你的目标、人脉、经历和想法，都是同一张地图上可以互相连起来的节点。

## 1. 从原始灵感里提炼出的三件事

原始灵感列了 10 个模块。逐条看下来，真正让它区别于"又一个待办 App"的是这三点：

1. **角色面板**：像游戏人物卡一样看见"我是谁、我在变强吗"。
2. **万物可关联**：任务、目标、人物、经历、灵感、情报之间可以任意互链，点一下就能顺着关系走。
3. **愿景树**：像技能树一样从终极目标往回倒推，不知道的阶段先填"？"。

其余模块（习惯、任务、经历、关系网）都是给这三件事提供数据的。

## 2. 关键产品决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 属性值从哪来 | **由行为产生，不由自评** | 自己给自己打"智慧 8 分"没有意义也不会更新。每个任务、习惯都归属一种属性，完成即为该属性加经验。 |
| 属性维度 | 智识、体魄、创造、社交、事业、心境 六维 | 覆盖学习、健康、创作、人际、财富/工作、情绪；六边形雷达图好看且好读。 |
| 惩罚机制 | **不扣分** | 游戏化最常见的失败是惩罚让人逃避打开 App。断掉的习惯只是连续天数归零。 |
| 拖延自动调整 | 逾期任务在"今日"置顶，一键「今天做 / 推到明天 / 放下」 | 原灵感要"自动重排"，但全自动排班需要大量规则配置，v1 改为一键的轻量调整。 |
| 分享方式 | **本地优先的网页应用（PWA）**，挂在静态网站上 | 想分享给别人用，又不想碰别人的隐私。程序公开，数据只在每个人自己的浏览器里，开发者也看不到。别人打开链接就能用，不用装任何东西。 |
| 账号登录 | **去掉** | 没有服务器，也就没有账号；登录只增加摩擦。 |
| 数据存放 | 浏览器 IndexedDB，可一键导出 / 导入 JSON 备份 | 隐私靠架构保证而不是承诺。风险是清浏览器数据会丢，所以：请求浏览器"持久存储"保护；两周没备份且有改动时在今日页提醒；从备份恢复视为已备份。 |
| 离线与安装 | Service Worker 预缓存全部页面；可"安装为应用" | 像本地软件一样用，断网也能打开。 |
| 技术栈 | Vue 3 + Vite，纯前端静态构建，无后端 | 原 Spring Boot + MySQL 只写了一天；v1 曾用 Node + SQLite 本机服务，2026-11-09 改为纯前端以便分享。 |

## 3. v1 范围

### 今日（首页，每天打开的地方）
- 问候 + 角色迷你卡（等级、经验条）
- 今日习惯：一键打卡，显示连续天数
- 今日任务：到期/进行中的任务；**逾期任务置顶**并提供三个处理按钮
- 心情：五档表情 + 一句话，每天一条
- 快速记录：随手记一条灵感或情报

### 角色
- 名字、称号、背景、特长、弱点、兴趣（文字档案）
- 总等级与经验、六维属性雷达与各属性等级
- 近 30 天心情条、统计（完成任务数、最长连续打卡、记录天数）
- 成就：由真实数据自动解锁的少量徽章

### 任务
- 状态：待办 / 进行中 / 完成 / 放下；截止日、难度（决定经验 10/25/50）、属性
- 可挂到愿景树的某个目标下，可设置前置任务（前置未完成时显示"锁定"）

### 习惯
- 每周哪几天做；按天打卡，连续天数，近 12 周打卡热力图

### 愿景树
- 树状图：终极目标 → 阶段 → 子目标；节点状态：未知（？）/ 未开始 / 进行中 / 达成
- 两个方向都能扩展：「添加下一步」（倒推）与「插入上层目标」（正推）
- 节点进度由挂载的任务自动计算

### 人物
- 关系图：以"我"为中心的同心圆，越亲近越靠内；按圈子（家人 / 朋友 / 同学同事 / 其他，由"关系"文字自动判断）着色，可按圈子筛选
- 人与人之间的连线 = 互相认识（复用通用关联）；选中一个人时高亮 TA 的连线
- 顶部统计：人数、近 30 天联系次数、该联系的人、30 天内生日
- 右侧档案：生日（年份可选，显示倒数与岁数）、怎么认识的、印象、亲密度
- **往来记录**：每次联系可写一句备注，按时间线展示，就是你们的交往史；每次 +5 社交
- 「好久没联系」提醒：按亲密度给出建议间隔；3 天内的生日会出现在今日页

### 经历
- 时间轴，按年份分组；类型：事件 / 里程碑 / 抉择
- 抉择类型记录当时的选项、最终选择和原因（原灵感的"人生阶段与选择"）

### 灵感与情报
- 灵感：萌芽 / 发展中 / 已转化 / 放弃；可一键转为任务或目标
- 情报：来源链接、标签，用来存收集到的资料

### 全局
- 任何条目详情里都有「关联」面板：添加关联、查看反向关联，点击跳转
- `Ctrl+K` 全局搜索与快速新建
- 明暗主题跟随系统
- 导出 / 导入 JSON 备份，备份提醒，存储保护状态
- 离线可用，可安装为桌面 / 手机主屏应用；多个标签页同时打开时自动同步

## 4. 暂不做（v2 候选）

- 财富与健康记账：专门的记账/健康 App 做得更好，v2 再考虑导入或简单记录
- 自动排班、自定义触发规则
- 多设备同步：v1 用导出/导入文件来回传；以后可做**端到端加密同步**（服务器只存看不懂的密文）
- 自动保存到本地文件（File System Access API，仅 Chrome/Edge）
- 语音记录、AI 总结
